0422 보강: 순열 조합 부분집합

src ~ 로부터  tgt ~ 개를 뽑는다.
1, 2, 3, 4, 5  -> __ __ __
	
순열
	perm(tgt (depth))
	모든 자리를 채우려고 src 를 고려할 때 전체
	제외 : 해당 자리 이전에 사용된 src => boolean [] select 로 src 만큼 만들고 각 자리를 채울 때 이 배열에 표시
	선택 : tgt 넣고, boolean [] select 에 해당 선택 표시

	swap
		순열은 모든 자리의 항목이 모든 가능한 순서를 바꾼다.
		__ __ __ __ __
	np
		3 2 5 1 4 -> 1 2 3 4 5 ~  5 4 3 2 1
		주어진 src 를 가장 작은 수로 정렬 -> 반복적으로 다음 큰수 다음 큰수 ..... -> 가장 큰수
		np() 현재 src 보다 다음 큰수를 만드는 역할
	
	np 조합
		src 5 -> tgt 3 일 때 bit or 배열로 5개 src 를 표현   0 0 1 1 1 (가장작은수) -> 1 1 1 0 0 (가장큰수)

조합
	src 중 한번 선택하면 그걸로 끝!
	배가 고프다. 길에 5개 식당이 있는데 3개를 선택
	원하는 tgt 만큼 선택을 하는데 src 는 한번 고려하면 그걸로 끝! (선택 or 비선택)
	src 를 순차적으로 선택하려고 하는데 이전에 고려했던 (선택했던 X) src 는 모두 버린다.
	select[] 기억 필요 X
	comb(src, tgt)

부분집합
	tgt 필요 X, src 만 고려
	부분집합은 공집합, 전체집합 외 모두 1 ~ src.length -1 개 로 구성된 모든 조합
	src 앞부터 뒤까지 하나씩 따지는데 선택, 비선택 2개로 구분
	기저조건에 도달했을 때, 최초 ~ 현재까지 진행되면서 결정한 선택, 비선택 기록 select[]
